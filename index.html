Laboratory Architecture Specifications

Inference Pipeline: This application executes quantized weights in browser via @mlc-ai/web-llm compiled with WebAssembly (Wasm) and Direct WebGPU compute kernels.

Weight Persistence: Neural tensor layers are stored in browser IndexedDB cache blocks. Your browser will retain them until site storage is explicitly cleared.

Compatibility: Requires Chromium 113+ (Google Chrome, Microsoft Edge, Brave) or modern Safari with WebGPU enabled.
